# ↺ OR ↻

**回すだけ。外へ、外へ。**

A minimalist circular puzzle with a red bead, rotating slotted rings, and only two decisions: `↺` or `↻`.

Playable prototype v0.1 is being assembled. It uses 16 fixed angular sectors and an exact breadth-first solver to verify the optimal number of decisions per stage.

No dependencies. The static app can be served from this repository and later published on GitHub Pages.
